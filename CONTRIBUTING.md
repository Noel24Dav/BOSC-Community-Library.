 Contributing to BOSC Community Library
Thank you for your interest! Please follow these steps to contribute:
1. Fork the repository[cite: 1].
2. Create a feature branch (`git checkout -b feature/AmazingFeature`)[cite: 1].
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`)[cite: 1].
4. Push to the branch (`git push origin feature/AmazingFeature`)[cite: 1].
5. Open a Pull Request[cite: 1].
